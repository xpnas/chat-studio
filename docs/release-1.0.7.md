# 1.0.7（8）紧凑输入栏与聊天附件

## 调整

- 输入框只保留一行操作：添加文件、模型、思考深度、语音、发送。移除独立 `/` 按钮。模型名过长省略，完整名称可通过提示/模型选择面板查看。
- 首字符输入 `/` 时，在整个输入框上方显示悬浮命令列表，沿输入框左右边缘对齐，不占输入框高度，不挤压消息列表。使用 OverlayPortal 跟随布局/键盘位置，限高滚动，选择后保留输入焦点；普通文本中间的 `/` 不触发。
- 聊天中 AI 回复的 Markdown 本地图片引用使用 Studio 鉴权缩略图接口显示，可点开缩放原图。Markdown 本地文件链接打开附件详情并可保存到系统选择的位置。
- 已有结构化图片/文件附件继续支持；附件卡片新增显式下载按钮，下载前不自动读取非图片文件。
- 下载按钮有防重复状态，错误可重试，切 Profile/注销丢弃过期响应，文件名去除路径分隔符和控制字符；不自动执行文件。

## 安全与范围

Markdown 只把本地绝对路径（Unix、Windows）或当前 Studio 同源的下载端点映射为鉴权附件请求。外部地址不会携带 Studio token；外部图片不会后台自动加载，点击后确认在浏览器打开。大文件仍执行既有 25 MB 下载上限，图片缩略图最多 8 MB；超限明确提示在 Studio 查看。

本轮修复的是 App 界面和附件展示/下载；不增加服务端文件访问权限。不存在/无权访问的路径仍由服务器返回 404/403。
