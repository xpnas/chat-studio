# 1.0.10（11）AI 音频附件直接播放

修复“AI 返回现成语音文件，只能下载”的遗漏。文字转语音与现成音频播放是两条独立路径：

- file / audio 内容块，MIME 为 audio/* 或通用 MIME 且扩展名识别为音频时，显示「播放语音」按钮；卡片点击也可播放。
- 点击 Markdown 本地音频链接或当前 Studio 同源下载链接，直接进入 App 播放，不再强制打开保存对话框。
- 下载按钮仍单独保留，可另存音频；播放已有语音不重新调用 TTS，不要求再配置 TTS。
- 原生播放器使用临时文件路径，不将整段音频载入 Dart 内存，不受旧的 25 MB 预览限制。
- 复用全 App 单播放器与鉴权请求：可取消加载/停止播放，聊天底部有统一播放状态与停止入口；播放结束/停止清理临时文件，切聊天/Profile、注销及后台停止。
- 支持识别 MP3、WAV、M4A、AAC、OGG、FLAC 等常见音频；实际解码支持取决于 Android/iOS 系统，解码失败明确提示，仍可下载。不支持的远程来源不自动携带 Studio 凭据。

## 验证与限制

静态分析通过；155 项本地测试通过，7 项环境相关测试默认跳过。新增识别、音频专用路径下载、不调用 TTS、文件播放、停止清理、Markdown 点击不弹下载、取消后不迟到播放测试。Android Release 编译和签名验证执行，签名沿用本次 1.0.6–1.0.9。

未连接真机，因此不宣称扬声器/蓝牙、特定 OGG/Opus 编码或全部音频样本已实听通过；iOS 无 Xcode，尚未本地编译。外部网站音频仍走确认外部链接流程。

前面报告的聊天恢复重复/闪动仍未修复，本版包含大文件下载修复及本次音频播放修复，不将二者混同。
