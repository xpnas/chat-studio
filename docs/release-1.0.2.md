# Ekko Mobile 1.0.2：历史阅读模式

- 手动向历史方向滚动超过 160 逻辑像素时，输入框自动折叠为底部的小入口，使用 180ms 高度动画扩大聊天可见区域；尊重系统减少动画设置。
- 回到最新消息（距底部 24 像素以内）自动展开；也可点击“展开输入框 / 继续编辑草稿”，不强制滚动、不强制唤起键盘。
- 小幅滚动、程序定位、分页和流式排版不会主动触发折叠；160/24 的不同阈值避免临界位置反复跳动。
- 同一个编辑器与原生媒体实例保留，草稿不丢失；输入框聚焦、录音、识别、选择/上传附件或已有待发送附件时保持展开。
- AI 生成时折叠栏仍提供停止按钮。切换或新建对话恢复输入框。
