# 隐私与安全说明

本说明描述当前客户端实现，不替代你所连接服务器自己的隐私政策。

## 本地持久化

- 系统安全存储：服务器地址、当前 Profile、设备登录 token、允许 LAN HTTP 的设置、随机安装 UUID。
- 普通偏好存储：主题设置。
- 不持久化：登录密码、聊天正文、思考内容、工具输出、模型供应商密钥。
- UUID 不读取 IMEI、广告标识或硬件序列号。iOS Keychain 的保存期限受系统行为影响，不能承诺卸载一定删除。
- Android 关闭自动备份，避免恢复不匹配的加密数据。

## 网络

请求直达用户指定的 Studio。无分析 SDK、广告 SDK、开发者遥测服务或自动第三方图片请求。公网连接要求 HTTPS；私网 HTTP 必须主动开启，且只建议可信隔离环境调试。

服务器返回的模型列表可能携带 Provider 凭据，客户端不保留这些字段；但它们可能短暂存在于请求解析内存中。不要把 HTTP 响应原文写入日志。

模型文本中的远程图片不自动加载；网页链接必须确认后才由外部浏览器打开。用户主动复制的内容会进入系统剪贴板，其他应用/系统行为不由客户端控制。

## 附件与语音

- 文件/相册选择由系统原生界面完成，不扫描媒体库，也不请求广泛文件系统管理权限。仅将你选中的附件在点击发送后上传至当前 Studio/Profile；图片发送前可本地预览。
- 录音只在用户主动点击且授予麦克风权限后启动；最多 60 秒。点击“完成”才上传识别；识别结果填入草稿，不自动发送消息。进入后台、切换对话/账号/Profile 会取消录音或丢弃已过期的识别结果。
- 音频通过 Studio 的 STT 配置处理，服务端可能再转发到其配置的第三方识别提供商。仅配置 TTS 不启用识别。手机不保存 STT 密钥。
- 正常结束、取消和页面释放时清理本应用创建的录音临时文件。系统文件/相册选择器可能产生系统或插件缓存；异常杀进程也可能留下临时文件，由系统清理或清除应用数据处理，不承诺安全擦除。
- 取消网络请求会尽力中断客户端上传，但已经抵达服务端的附件/音频不保证撤回；当前通用上传接口没有客户端使用的撤回协议。上传后发送失败可能留下服务端文件，清理与保留期限由管理员管理。
- 历史附件显示文件名，不自动下载历史图片或任意外部图片。文档能否解析、图片能否理解取决于服务端 Agent/模型能力；上传成功不意味着任何模型都支持视觉或所有文件格式。

## 服务器与工具

聊天、账号、设备绑定及历史存储由 Studio 管理。删除对话调用服务器删除接口；具体清理、备份保留由服务器决定。手机退出只删除本地登录信息，设备 token 的服务端撤销需通过 Studio 管理界面完成。

工具执行发生在服务器，可能影响服务器文件或外部系统。客户端提供“仅本次允许 / 拒绝”，不自动批准，不离线排队重放。授权超时和最终权限由服务端强制校验。

本客户端未增加截图阻止、应用锁或后台缩略图遮挡；若使用场景对这些有要求，需要额外增强并在真机验证。
