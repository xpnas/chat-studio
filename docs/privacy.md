# 隐私与安全说明

本说明描述当前客户端实现，不替代你所连接服务器自己的隐私政策。

## 本地持久化

- 系统安全存储：多个服务器各自的地址、Profile、设备登录 token、允许 LAN HTTP 的设置，当前选中服务器和随机安装 UUID；按服务器、账号 ID 和 Profile 分隔的最近模型 ID、提供商 ID、引擎和思考深度偏好（不包含供应商密钥）。
- 普通偏好存储：主题设置、是否已展示阅读入口引导。
- 不持久化：登录密码、聊天正文、思考内容、工具输出、模型供应商密钥。
- UUID 不读取 IMEI、广告标识或硬件序列号。iOS Keychain 的保存期限受系统行为影响，不能承诺卸载一定删除。
- Android 关闭自动备份，避免恢复不匹配的加密数据。

## 网络

请求直达用户指定的 Studio。无分析 SDK、广告 SDK、开发者遥测服务或自动第三方图片请求。公网连接要求 HTTPS；私网 HTTP 必须主动开启，且只建议可信隔离环境调试。

服务器返回的模型列表可能携带 Provider 凭据，客户端不保留这些字段；但它们可能短暂存在于请求解析内存中。不要把 HTTP 响应原文写入日志。

模型文本中的远程图片不自动加载；网页链接必须确认后才由外部浏览器打开。用户主动复制的内容会进入系统剪贴板，其他应用/系统行为不由客户端控制。

## 附件与语音

- 文件/相册选择由系统原生界面完成，不扫描媒体库，也不请求广泛文件系统管理权限。仅将你选中的附件在点击发送后上传至当前 Studio/Profile；图片发送前可本地预览。
- 录音只在用户主动点击且授予麦克风权限后启动；最多 60 秒。点击“完成”才上传识别；识别结果填入草稿，不自动发送消息。进入后台、切换对话/账号/Profile 会取消录音或丢弃已过期的识别结果。
- 音频通过 Studio 的 STT 配置处理，服务端可能再转发到其配置的第三方识别提供商。仅配置 TTS 不启用识别。手机不保存 STT 密钥。
- 正常结束、取消和页面释放时清理本应用创建的录音临时文件。系统文件/相册选择器可能产生系统或插件缓存；异常杀进程也可能留下临时文件，由系统清理或清除应用数据处理，不承诺安全擦除。
- 取消网络请求会尽力中断客户端上传，但已经抵达服务端的附件/音频不保证撤回；当前通用上传接口没有客户端使用的撤回协议。上传后发送失败可能留下服务端文件，清理与保留期限由管理员管理。
- 历史附件显示文件名、类型与已知大小。列表可见图片通过带 token / Profile 的 Studio `/api/studio/files/download?variant=app-image` 路由读取缩略图，不能自行访问附件路径对应的外网 URL；模型 Markdown 外链图片仍不自动加载。缩略图原始字节只保留在有限内存缓存（最多 12 项 / 12 MiB），关闭 API 会话时清理；解码图片由 Flutter 内存图片缓存管理，不持久化到磁盘。原图仅用户打开预览时读取（内存预览上限 25 MiB）；原文件保存使用流式下载到临时文件，不受该预览上限限制，关闭窗口会取消读取；保存需要用户主动选择系统目标位置。文档能否解析、图片能否理解取决于服务端 Agent/模型能力；上传成功不意味着任何模型都支持视觉或所有文件格式。

## 服务器与工具

聊天、账号、设备绑定及历史存储由 Studio 管理。删除对话调用服务器删除接口；具体清理、备份保留由服务器决定。手机退出只删除当前服务器的本地 token，保留地址/Profile 与其他服务器登录；删除非当前服务器记录同时删除其本地 token，设备 token 的服务端撤销需通过 Studio 管理界面完成。

工具执行发生在服务器，可能影响服务器文件或外部系统。客户端提供“仅本次允许 / 拒绝”，不自动批准，不离线排队重放。授权超时和最终权限由服务端强制校验。

麦克风音量检测只在录音期间从原生插件采样，不在后台持续监听；无声提示是音量阈值判断，不是语音内容分析。失败消息的重试内容和服务器附件引用只保留于各会话内存；未知是否送达的消息不会被自动重发。

退出登录清除当前服务器 token 和当前会话内存，但最近模型/引擎偏好保留用于下次同账号登录；它们不包含密码、模型密钥或聊天内容。

本客户端未增加截图阻止、应用锁或后台缩略图遮挡；若使用场景对这些有要求，需要额外增强并在真机验证。

## 发布者责任

正式发布需填写你的支持渠道、组织身份、商店隐私表和账号删除流程；本项目不伪造这些运营信息。Apple / Google 上架、签名和隐私审核不等同于编译成功。


## 多会话运行与草稿

- 已打开对话的正文、运行状态、权限提示、文本草稿、已选附件/服务器附件引用和阅读位置按 Profile + session_id 分离，只在进程内存中保留；新建未发送草稿也按 Profile 分开。退出登录会清理这些状态，不作为离线聊天数据库保存。
- 切换聊天不会发出 abort；服务端任务可能继续执行并产生供应商费用。停止按钮明确作用于正在查看的会话，删除仍在执行/待确认/待同步的任务会话被阻止。
- 当前仅维持选中 Profile 的 Socket.IO 连接。同一 Profile 的已订阅会话事件分别路由，其他 Profile 的运行状态会标为待同步，返回后通过快照/resume 核对，不伪造跨 Profile 实时状态。
- 切换聊天时，正在录音/转写/上传的客户端操作会取消或忽略迟到结果，但保留已有草稿和已选附件。取消请求不保证撤回已到达服务端的数据。切换聊天不等于撤回已经开始的 Agent 执行。
- 缓存优先淘汰没有草稿的空闲完成会话；运行/待确认/有草稿的会话保留。杀进程后的草稿恢复、跨设备草稿同步不在本版本范围内。

## 多服务器与 Agent 标识

- 旧版本的单会话记录会迁入安全存储的服务器列表；同一标准化地址保留一个登录记录，重新登录替换旧 token，不保存密码。
- 切换/添加服务器会关闭旧网络客户端和 Socket、停止播放、清空聊天/草稿/附件状态。其他服务器后台任务仍可能继续执行并产生费用，需切回对应服务器查看。
- 过期或撤销的授权仅清除该服务器 token，保留配置供重新登录。删除记录不撤销远端设备授权；应到对应 Studio 管理设备。
- Agent 图标只从当前服务器固定的 `/coding-agents/` 静态路径读取，不携带登录 token；不把聊天/个人数据传给第三方图标服务。资源加载失败时使用本地回退标识。
- AI 音频附件不再提供识别/转文字入口；只有用户主动完成麦克风录音后才走语音输入 STT 流程。
