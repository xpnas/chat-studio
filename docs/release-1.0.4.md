# Ekko Mobile 1.0.4：聊天体验细节

移动端 `1.0.4+5`，服务端兼容版本仍为固定 SHA 的 hermes-studio v1.0.3。

## 已实现

1. **流式排版**：流式和完成后使用同一个 Markdown 分段渲染组件，已完成分段复用，末段更新；代码围栏、列表与表格保持块完整。没有承诺生成内容被服务端修改时绝不重排。
2. **阅读稳定**：在可见段落/文字位置记录锚点，流式和历史变更后校正；翻页保留已加载早期记录；回看中收到正文显示小“新”徽标，用户点击才回到底部。
3. **消息状态**：用户气泡旁显示等待确认、核对中、失败、停止；未知是否送达不提供自动重试。明确失败后“编辑后重试”只恢复草稿和远端附件引用，需要再次主动发送；已有草稿/录音/上传不会被覆盖。上传错误在输入区显示，仍保留草稿。
4. **回答分组**：相邻 AI 正文、思考和工具状态归于一轮，身份标记仅一次，操作详情默认折叠；工具 ID 去重，不把输出日志当正文。
5. **悬浮双线**：首次使用短暂引导（一次性偏好）、闲置 3 秒后轻微淡化（仍可辨认/点击）、滚动恢复对比度、180ms 进度插值。百分比仍仅指已加载历史范围。
6. **模型记忆**：按服务器 + 账号 + Profile 保存模型/提供商/引擎，新建沿用；打开历史不覆盖新对话偏好；上次模型不可用或 Codex 未安装时提示回退。
7. **附件**：已发送图片缩略图、点击大图；文档类型/已知大小、系统保存入口，缺失/失效/拒权显示重试状态。未知大小明确写“大小未知”。鉴权限定服务端读取、拒绝重定向，内存缓存与下载体积有界。上传百分比来自实际请求流字节，100% 表示发送完请求体，仍等待服务端保存；不是虚构计时进度。
8. **语音**：原生真实音量采样条，持续 5 秒低音量提示检查麦克风；录音/识别状态区分，转写追加至草稿并把光标置末尾，不自动发送。

## 验证 / 边界

- 新增 27 项专项测试；总计 97 项单元/组件回归，另运行 3 项真实 Studio 契约测试和 1 项设计预览。
- 新增附件鉴权读取/图片优化真实联调，并修正开发数据库隔离；仅使用隔离服务及本地模型/STT 夹具。
- **真机验收未完成**：当前无 adb 设备/模拟器，未测真实录音、文件保存、键盘手势、能耗或 FPS；无 macOS/Xcode，iOS 编译/安装仍未验证。系统保存后的第三方文档阅读器、任意格式及复杂 Markdown 扩展不在本次保证范围。
- 文档可保存后由用户在系统应用中查看，未加入 Office/PDF WebView 渲染器；保持客户端轻量。
- Android Release APK/AAB 使用原签名、versionCode 5，产物 `dist/ekko-mobile-1.0.4-android-release.apk` / `.aab`，不提交签名或包文件到 Git。
