# 1.0.9（10）大文件下载

原 App 的保存逻辑调用 attachmentBytes，与原图预览共用 25 MB 上限，导致约 59 MB 的 Release APK 无法保存。本版本将下载与内存预览分离。

- 下载使用 Studio 同源鉴权接口，逐块写入 App 临时目录，等待磁盘写入完成再读取下一块，不将整份 APK 聚合到内存。
- 原有 25 MB 内存预览与 8 MB 缩略图限制保留，不再用作下载限制。
- Android 使用 ACTION_CREATE_DOCUMENT 选择保存位置，在后台线程通过文件流复制到系统文档 URI；无需广泛存储权限，不通过 MethodChannel 传输完整文件字节。
- iOS 实现基于临时文件路径的 UIDocumentPicker 导出；本机无 Xcode，未编译/真机验证 iOS。
- 显示已下载 MB/总大小（服务端未给长度时显示不确定进度）；下载过程中可取消，系统保存阶段通过系统对话框取消。
- 禁止携带 Token 跟随重定向；401/403/404、连接中断、Profile 变化、磁盘写入失败明确报错。失败清理临时文件，不将残缺文件当作下载成功。
- 响应头等待 45 秒、连续无数据 60 秒、总时长 30 分钟后停止，避免无限占用资源。实际可下载大小仍受剩余存储、系统文件提供商及服务器/代理限制，不宣称无限下载。

## 验证

本地静态分析通过，151 项测试通过、7 项按环境默认跳过。新增 64 MB 流式 APK、取消清理、跨 Profile 响应、401/403/404/302、不完整响应回归。未连接真机，系统保存对话框、系统云盘目标/磁盘不足和 Activity 重建需后续真机验证。

旧版 App 仍会限制更新包下载，请先用 Web/浏览器下载 1.0.9。签名沿用本次已交付的 1.0.6–1.0.8，可以覆盖这些版本。
