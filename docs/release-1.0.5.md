# Ekko Mobile 1.0.5

移动端版本 `1.0.5+6`，服务端兼容版本仍为固定 SHA 的 hermes-studio v1.0.3。

## 本轮完成

1. **执行中切换聊天**：拆分选中界面与会话运行状态；切换不 abort 原任务，输出、工具授权、错误、同步与发送确认定时器分别属于各会话。已打开对话的草稿、附件和阅读位置保留。当前 Profile 可并行发起不同会话，单个会话仍防止重复发送。
2. **思考深度**：输入框提供默认/关闭/极低/低/中/高/极高/最高，使用真实 `reasoning_effort` run 参数及会话 REST 配置；重连从服务端恢复，切换模型重置，运行中的当前会话不改变参数。后台 A 运行不妨碍为 B 配置深度。效果受引擎、模型能力限制。
3. **任务历史标记**：基于服务端 `session.activity.snapshot` 和 `session.activity`，运行任务使用轻量环形动画；待确认、待同步、完成、失败分别标记。减少动画模式使用静态标记，不显示假的百分比。
4. **列表紧凑化**：标题 13px、摘要 10.5px，行高约 54px，缩小上下间距，保留管理按钮的可点击区域。运行条目仍可打开，不能误删正在执行的会话。

## 验证与边界

- 新增 25 项多会话/思考深度测试，完整单元/组件测试 122 项；真实 Studio 契约套件 4 项，设计预览 1 项。
- 新真实场景已覆盖两个会话同时工作、另一设备通过快照观察运行状态、切回原任务、独立停止及思考深度配置重连读回。
- Profile 切换会重新建立该 Profile 的订阅；未连接 Profile 的后台任务状态是待同步，不声称后台所有 Profile 永远实时。
- 本次多会话状态/草稿缓存为内存，不做离线历史持久化。缺失快照、同步错误或未知送达状态保守核对，不自动重发消息/授权。
- 没有连接 Android 真机；iOS 共享源码已更新，但无 Xcode 编译/安装验证。真实 Codex CLI、多供应商并发限额及手机性能仍需实际环境验收。
- APK/AAB 沿用原签名，versionCode 6，产物 `dist/ekko-mobile-1.0.5-android-release.apk` / `.aab`；包和签名资料不提交 Git。
