# Ekko Mobile 1.0.3：悬浮双线阅读入口

这是移动端版本 `1.0.3+4`；兼容的服务端仍为原固定源码 hermes-studio v1.0.3。

## 视觉与交互

- 移除上一版整行“展开输入框 / 继续编辑草稿”文字底栏。正文延伸到安全区底部，双线悬浮在阅读区域上方，不为它预留 footer 高度。
- 上方淡灰线是 96px 轨道，下方青绿色细线从中心向两侧伸长，反映当前已加载历史中的回看位置；线宽约 2.5px、圆头、轻柔背景光晕，分别调整浅深主题的对比度。百分比不常驻显示，避免抢正文注意力。
- 视觉线条很轻，实际透明点击范围为 128 × 48px。轻点恢复原输入框，不跳回底部、不强制打开键盘；无障碍语义与长按提示提供入口说明和进度。
- 进度 = 距最新位置的滚动距离 / 当前已加载内容的可滚动范围。它不是所有服务端历史消息的精确条数比例；分页加载更早消息后，范围与进度重新计算。空列表与越界滚动有安全处理。
- 使用局部 ValueNotifier + RepaintBoundary 绘制进度，滚动时不为更新线条重建整个聊天页面。
- 停止生成与回到最新消息在右侧错开；双线位于系统底部安全区内。录音、识别、上传、待发送附件和待处理权限确认不强制折叠。

## 验证 / 交付

- 阅读组件回归共 11 项：原有恢复/草稿/媒体保护，新增零 footer 布局、进度随滚动及分页范围更新、浅深主题透明点击区、空范围/越界、320px 屏幕系统手势区与按钮避让。
- 本轮只改 UI，不重复运行真实服务端契约测试。iOS 为共享源码更新，没有本地 Xcode 构建或真机验证；没有宣称测试了真机帧率或麦克风准确率。
- Android APK/AAB 沿用原签名，versionCode 4，文件名 `dist/ekko-mobile-1.0.3-android-release.apk` / `.aab`，校验和及构建记录同目录。
