# Ekko Mobile 1.0.1

## 本轮改动

1. 新的青绿渐变六瓣交织图标；独立代码绘制，Android/iOS 与应用内一致，不代表 ChatGPT 官方客户端。
2. Codex 新建引擎、服务端安装状态检测、scoped run 路由与历史续聊。
3. 紧凑对话排版：空工具行不显示头像，思考折叠、正文优先；用户淡青绿/AI 极淡灰圆角底，适配浅深主题。
4. 移除底部“AI 的回答可能有误”提示。
5. STT 驱动语音输入：权限检查、60 秒限制、完成后可编辑、取消/后台停止、过期结果隔离。
6. 模型提供商父子树：当前提供商自动展开并置顶，当前模型首位标记，其他组可折叠，搜索保留父级。
7. 原生文件与相册选择，发送前图片预览、移除和大小数量限制；multipart 上传后以服务端内容块发送。

## 验证范围

真实 v1.0.3 后端 + 本地模型/STT 夹具已通过文件/图片上传 → Ekko 对话 → 持久历史、音频上传 → 服务端 STT → 文字返回，以及原有重连/中止/账号接口联调。

夹具返回确定性识别文字，**不是实际麦克风识别准确率测试**；没有调用收费模型。Codex 已覆盖路由/历史回归，未用真实 Codex CLI 调用模型。iOS 尚未在 Xcode 或真机编译运行；原生权限、相册、录音与实际帧率需要 Android/iOS 真机验收。
