# 1.0.14（15）前台恢复消息重复修复

## 问题

App 从后台回到前台时，正在生成的最后一条 AI 消息偶发部分重复并闪动。服务端恢复同时包含数据库快照、工具步骤和事件缓冲；进入后台前 App 也可能已经显示了部分实时增量。

## 修复

- 恢复前保留已有流式助手前缀和 renderKey，禁止因恢复重新生成气泡身份。
- 使用 runMarker/finishReason 识别同一轮 assistant，即使快照最后一行是 tool 也能合并到正确气泡。
- 当前 run 事件在独立 reducer 中重放；完整回放以事件序列为权威，截断回放使用线性重叠匹配，仅追加未显示尾部。
- 没有 run.started 的截断恢复不做全局文本去重，只在当前 run 可证明时拼接，正常重复词语保留。
- 已完成 run 不允许被迟到的 working resume 快照复活。
- 前后台切换时不重发 run；后台事件恢复仍通过 resume。

## 验证

新增前台恢复回归：重复切换前后台、事件缓冲截断、快照含工具行、正文/思考内容重叠、完成后迟到快照、普通重复词语，以及发送次数不增加。

本地完整测试 175 项通过，静态分析无问题；隔离官方 v1.0.3 服务端真实联调 7 项通过，包含 200+ 事件缓冲截断后的前后台恢复。服务端运行事件上限仍为 200，升级 Studio 后应继续复跑。

当前未连接 Android 真机，尚未进行真实系统进程被杀、低内存回收、蜂窝/ Wi-Fi 切换下的实机验收。
