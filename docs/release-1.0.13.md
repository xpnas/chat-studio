# 1.0.13（14）自动加载较早历史

- 移除正常状态下必须点击的“加载更早的消息”按钮。反向列表距历史顶部 240 逻辑像素内自动请求下一页，远离顶部不预取。
- 初始内容不足一屏、只有不可见 tool 行的分页继续按原始行 offset 补齐；真正没有更多消息时停止。
- 请求在布局完成后触发，不在 build/layout 中同步修改状态；每个会话仅允许一个历史请求进行，滚动通知/流式刷新不会重复拉同一页。
- 沿用反向列表的稳定消息 key、阅读锚点及会话草稿滚动位置，分页不强制跳到最新消息。
- 离线、恢复同步中不请求；切会话/注销后的迟到回执不会污染当前会话。恢复快照继续作废过期分页请求。
- 自动分页失败在历史边缘提示重试，暂停自动循环，避免弱网下不断弹错；分页 offset 不推进时同样停止并提示。
